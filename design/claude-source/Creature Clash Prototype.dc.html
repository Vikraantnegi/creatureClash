CREATURE CLASH · INTERACTIVE PROTOTYPE

Both flows, every state

Click through the phone. Timers are real; the pause state triggers when this tab is backgrounded, or with the button below. Creature art is the pass-2 set.

Tweaks: timer speed · opponent behaviour
1 · Flow map
Home ├ A Pick (you: exact · opp: clues) → Matchup → DUEL → Result → Rematch | Change picks └ B Preview six → Lock three [30 s] → ┐ ┌────────────────────────────────┘ │ Secret pick [15 s] → Waiting → Pair reveal → DUEL → Duel result ─┐ ×3 └──────────────────────────────────────────────────────────────────┘ Encounter result ─ win → Exchange (give / receive) → Confirm | Decline → Roster ─ loss → Trainer's claim (explain → acknowledge) → Roster ─ draw → Roster Roster → Next encounter | Home DUEL Select [10 s] → Locked (waiting) → Reveal → Continue ↳ ×3 · HP 0 ends early · tie after 3 → Exchange 4 (automatic, separate reveal) ↳ Timeout → first unused of ATK · DEF · SPD · SPC, marked on the reveal ↳ Backgrounded → Paused (time preserved) → Resume
2 · Visual direction
Paper and ink. Warm parchment ground (#F3EEE4), one ink (#1F1B18) for all chrome, rust (#8A3A22) only for kickers and the outgoing side of a swap. Type is Helvetica for reading and monospace for game data, so numbers always look like numbers. Creatures are the only saturated colour on screen.
Meaning never rides on colour alone: solid border = yours / known, dashed = theirs / hidden, strikethrough + "USED" = spent, filled pill = HP, outline pill = lost HP. Every result is a word (WON · LOST · TIE) as well as a fill.
3 · Component inventory
CreatureTileportrait sprite, name, type, optional exact stats; states: default · selected · disabled · used · hidden (dashed, "?") HpCardname, type pill, 2 HP pips + text; sides: yours (solid) / theirs (dashed values) CategoryRowname, base → effective, opponent clue or played value; states: available · selected · locked · used-by-you · used-by-them · disabled CommitBarprimary "Lock in X" → dashed "Locked · waiting…" (never re-enables) TimerPill + Barmm:ss, turns filled at ≤ 3 s; bar drains linearly; freezes on pause RevealPanelkicker, two value cards (winner filled), title, explanation, single CTA; variant: automatic 4th exchange ResultSheettitle, sprites in mood, exchange history rows, two actions ScoreBlockgym score, never mixed with exchange or duel counters SwapCard pairLEAVES YOU (rust) ⇄ JOINS YOU (ink) PauseScrimfull-screen, remaining time, single Resume Headerclose · primary counter (Exchange n of 3) · secondary line (Duel n of 3 · Gym a–b)
4 · Assumptions
· Type chart: each type beats exactly one other (Fire→Grass, Grass→Water, Water→Fire, Electric→Water, Rock→Electric) and adjustment is ±2 on every category. Replace with the engine's real table; the UI only ever shows "base → effective" and a one-line reason.
· Individuals vary ±1 from species values, so a clue can be wrong for a given creature — the copy says "species tendency" everywhere.
· On a 30 s lock timeout, the first unselected roster members fill the empty slots; on a 15 s pick timeout, the first unused of your three is sent.
· "Waiting for opponent" lasts ~1 s against the local AI; against a remote player it would hold until their commit.
· The opponent's exchange picks the first participants on both sides, as in the current local prototype — flagged provisional in-UI.
· Opponent values revealed during a duel are the ones shown on a received creature after a swap.
· No back navigation once a commit exists; ✕ abandons the duel (counts as nothing) — a confirm dialog is out of scope here.
