Reduced motion · implementation notes
· Reduced motion (useReducedMotion()): all scale/translate become opacity-only at 120 ms; the 400 ms result delay drops to 0 so cards and verdict land together; the pulsing dot becomes a static dot with "waiting…"; the HP pip switches instantly. Timer bar keeps draining — it is information, not decoration.
· Total time from opponent commit to actionable CTA: 640 ms normal, 120 ms reduced. Nothing else is gated on animation.
· No creature motion on hit. Sprites only change expression (confident / defeated) when HP changes; no lunges, flashes or shakes that would imply an attack resolved against a defence.
· Timer: store deadline in state; render with a 100 ms interval; on AppState inactive/background persist remaining = deadline − now; on active show the scrim and only rebuild the deadline on Resume.
· Timeout is decided by the engine, not the UI: the client sends the auto-pick with a reason:'timeout' flag so the reveal can label it.
· Opponent's value is never in client state before both commits; the row shows theirs.kind only. The Debug toggle above reads a separate dev-only payload.
· NativeWind tokens: ink #1F1B18 · paper #FBF9F4 · parchment #F3EEE4 · sand #E2DACA · rust #8A3A22; radius-xl 12, radius-2xl 14; mono for every number.
